Design System

Lumen — Design System

A unified component library scaling design consistency across five product teams.

Role
Design Systems Lead
Timeline
4 months, ongoing
Platform
Figma + React
Tools
Figma Variables, Storybook, Zeroheight
Lumen — cover

The Problem

Five product teams had each built their own version of a button, a card, a modal — inconsistent spacing and colour made the product feel like five different apps stitched together.

None of the teams had time set aside for "design system work," so adoption had to happen incrementally, alongside their existing roadmaps, not instead of them.

Process

Audited 40+ existing components across teams, consolidated the overlap into token-first primitives, and ran a working group with one designer/engineer pair from each team so no team's constraints got missed.

The Solution

A token-driven component library — spacing, colour, and type as variables — with matching React components and living documentation, rolled out one team at a time instead of as a single migration.

Results

Duplicate components started disappearing from the codebase within the first quarter, and handoff got noticeably faster once both sides were speaking the same token names.
